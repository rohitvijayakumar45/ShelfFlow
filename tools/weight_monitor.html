Quick calibration before a demo · 44 g, under a minute

Press Start, then follow the prompt: tray empty, mass over A (left), over C (right), at the centre, then off. Each move is detected on its own; just let go each time. It recalibrates both cells, checks the centre, and zeros the empty tray; the zero then follows temperature drift automatically while the tray is empty. Best accuracy for about 5 minutes.

Step-by-step calibration (fallback) · one 44 g weight

Capture the empty tray, then move the same 44 g weight over the left cell (A), then over the right cell (C). Release it and keep hands off for every capture. Finally move it to the centre for an independent check and save.

Reading controller calibration state…

Each capture records both raw channels. The solver fits one fixed gain per cell so their sum equals 44 g at both positions. Empty capture alone does not save a new calibration. The centre check must pass within ±2 g before saving; unstable, missing or saturated channels block capture.

Waiting for live A and C readings from the controller…

Raw drift = current ADC count − reference ADC count. Range and noise use the selected chart window. Drift in grams is shown separately and uses the stored calibration. Changing the drift reference only changes this window; it does not tare or recalibrate the ESP32. Samples arrive about once per second. Keep the load unchanged when checking drift.
